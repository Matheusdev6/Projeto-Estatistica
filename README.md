# Projeto-Estatistica
## Descrição do projeto

Projeto voltado para estudo de desenvolvimento Full-Stack com React.js, C++, Python, FastAPI, Docker e PostgreSQL. Além disso, busco estudar e aplicar conceitos apredidos durante minhas aulas de Probabilidade e Estatística I, em que estou aprendendo a coletar dados, e estruturar certas métricas a partir deles.

No projeto, busco dados públicos do Governo do Brasil, que armazeno e utilizo como base para as métricas.
Os dados são atualizados a cada 2 meses por um script que os coleta, normatiza e os armazena no banco de dados da aplicação.

Os usuários pedem qual tabela querem consultar, cálculos que querem, e o período de tempo pela interface em React. O back-end recebe a requisição, calcula os valores, e retorna os dados prontos.
Após isso, gráficos são plotados com o auxílio de ferramenta da linguagem JavaScript.

*IMPORTANTE*: o projeto está em fase de desenvolvimento, portanto, pode sofrer alterações. Vou realizar testes comparando a performance com C++ e Python puro. Após os testes, vou documentar os resultados aqui e escrever qual foi a descisão conforme os dados.

## Uso de IA
O projeto será construído parcialmente com o uso de Inteligência Artificial (LLMs). Seu uso estará focado em aprender sintaxes das linguagens, pois sou mais acostumado com Java, e em debuggar alguns trechos de código, se necessário.
