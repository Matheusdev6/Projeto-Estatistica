# Projeto Estatística

## Descrição Geral
Projeto desenvolvido para consolidar conceitos de estatística vistos na graduação, integrando-os a uma aplicação Full-Stack (API REST, Banco de Dados Relacional e Interface Web).

## Arquitetura e Stack
* **Frontend:** React.js
* **Backend (API REST):** Java com Spring Boot
* **Motor de Cálculo:** C++ *(integração de alta performance)*
* **Banco de Dados:** PostgreSQL
* **Infraestrutura:** Docker *(em breve)*

> **Nota sobre Performance (¹):** A escolha inicial do C++ para a camada de cálculos visa otimização e velocidade. Testes comparativos entre Java e C++ serão realizados e documentados futuramente nesta seção.

## Uso de Inteligência Artificial
O uso de LLMs neste projeto é estritamente limitado à consulta de sintaxe de linguagens/frameworks e auxílio na depuração (debugging) de código.
